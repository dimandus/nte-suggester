# Подборщик команд для Neverness to Everness

Локальное приложение для своих четвёрок. Оно не ходит в сеть и не подменяет внутриигровое меню: открывается в браузере на этом компьютере.

Состав базы — версия 1.4 на 10 ноября 2026. Элимс и Экзе в списке есть, в автоподбор они попадают только если отмечены как имеющиеся.

## Как запустить

Нужен [Node.js](https://nodejs.org) (подойдёт текущая LTS).

1. Скачайте архив релиза и распакуйте его.
2. Запустите `Запустить.bat`.
3. Не закрывайте чёрное окно. Пока оно открыто, подборщик работает. Браузер откроется сам на `http://127.0.0.1:5173/`. Если страница не нашлась, вставьте в адресную строку именно этот адрес, не `localhost`.

Первый запуск ставит зависимости и может занять минуту. Чтобы выключить приложение, закройте окно или нажмите Ctrl+C.

Из папки проекта то же самое делается так:

```bash
npm install
npm run dev
```

## Что внутри

- **Персонажи.** Имена и портреты как в русском справочнике. У каждого теги, параметры четвёрки, усиления цикла, консоли с приоритетом основного стата и дуги.
- **Дуги.** Английские имена, короткий пересказ эффекта.
- **Справочная.** Стихии, реакции, классы, консоли.
- **Команды.** Рельсы (входящие и исходящие сразу, без повторов персонажей), пять общих пачек и доборщик: закрепляете слоты, остальные заполняются сами.

Отметка «в наличии» хранится в браузере, в `localStorage`. Временный бонус этажа можно записать, в счёт он пока не идёт.

## Как устроен подбор

Счёт свой, это не официальный тир. Четвёрка набирает очки за стихии этажа, реакции, усиления цикла и параметры персонажей: кто долго стоит на поле, кто сразу заполняет шкалу, кому нужна долгая или обновляемая Ремора, кому нужно пробитие. На рельсах пара комнат выбирается по сумме, а не по каждой комнате отдельно.

Нового персонажа описывают тегами и параметрами в `src/data/characters.ts`. Вес в этой карточке внутренний и не копируется из чужого списка.

Где открытые источники расходятся, в карточке стоит пометка. Числа пассивок, которых в источниках не было, в базу не вносились.
